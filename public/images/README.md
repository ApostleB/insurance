# 이미지 디렉토리

## og-image.png (직접 추가 필요)

카카오톡·SNS 공유 시 노출되는 미리보기 이미지입니다.
아래 규격으로 만들어 이 폴더에 `og-image.png` 이름으로 넣어주세요.

- 권장 크기: **1200 × 630 px** (카카오톡은 800 × 400 이상 권장)
- 파일 크기: 1MB 이하
- 내용 예시: 설계사 이름 + "여러 보험사를 한 번에 비교" 같은 한 줄 문구

이 파일이 없어도 사이트는 정상 동작하지만, 공유 시 미리보기 이미지가 표시되지 않습니다.
경로는 `src/app.ts`의 `res.locals.ogImage` 에서 변경할 수 있습니다.
